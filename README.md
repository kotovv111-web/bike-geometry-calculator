# Bike Geometry & Fit Calculator

Вебзастосунок на React 19, TypeScript і SVG для порівняння геометрії двох велосипедів та положення центра затискача керма. Інтерфейс українською, працює локально без серверної частини та зовнішніх API.

## Запуск

Потрібен Node.js 22.12+ (перевірено на 24.19) і npm.

```sh
npm ci
npm run dev
```

Vite запускає сервер на порту 5173; відкрийте `http://localhost:5173/bike-geometry-calculator/`. `npm run build` перевіряє TypeScript і створює `dist/`; `npm run preview` дозволяє перевірити production-збірку.

## Реалізовано

- Незалежні параметри та назви велосипедів A/B, приклади Endurance і Race.
- Stack/Reach, кути та довжини труб рами, нижні пера, колісна база, опускання каретки й радіус коліс.
- Довжина та кут виносу, проставки, кришка рульової і висота затискача виносу.
- Розрахунок горизонтального й вертикального положення керма, ефективної верхньої труби, виносу вилки та трейлу.
- SVG із суміщенням за кареткою, перемиканням накладання та розмірів, автоматичним масштабуванням.
- Таблиця порівняння B − A й опис зміщення керма.
- Перевірка числових меж, збереження останніх коректних параметрів у localStorage, скидання прикладів та адаптивний інтерфейс.

## Математична модель

Початок координат — центр каретки; X вперед, Y вгору. Всі довжини в мм, кути в градусах. Stack S і Reach R рами вводяться з таблиці виробника; проставки їх не змінюють.

Нехай α — кут рульової до горизонталі, β — кут підсідельної, L — довжина виносу, γ — кут виносу від перпендикуляра до рульової осі, h = проставки + кришка рульової + половина висоти затискача.

```text
верх рульової = (R, S)
центр затискача на штоку = (R − h cos α, S + h sin α)
напрям виносу θ = 90° − α + γ
центр керма X = R − h cos α + L cos θ
центр керма Y = S + h sin α + L sin θ
ефективна верхня труба = R + S / tan β
задня вісь = (−√(нижні пера² − BB drop²), BB drop)
передня вісь = (задня вісь X + колісна база, BB drop)
низ рульової = (R + довжина рульової cos α, S − довжина рульової sin α)
винос вилки f = (передня вісь X − низ рульової X) sin α
               + (передня вісь Y − низ рульової Y) cos α
трейл = (радіус колеса cos α − f) / sin α
```

Креслення схематичне. Підсідельна труба — від каретки до її верху, підсідельна вісь пряма. Колеса однакового радіуса. Не враховані сідло, форма керма, ручки, положення долонь, підвіска та деформації. Винос вилки виводиться з введеної геометрії, а не задається незалежно. Суперечливі розміри можуть давати фізично нереалістичну геометрію. Максимальну допустиму висоту проставок визначає виробник вилки. Це не персональний медичний чи біомеханічний bike fit.

## Перевірки

```sh
npm test
npm run build
```

П'ять тестів перевіряють координати рами/осей, зміщення від проставок, горизонтальний винос, формули верхньої труби та трейлу, відхилення некоректних значень.

Браузерна перевірка потребує запущеного сервера (`npm run dev` в окремому терміналі):

```sh
npx playwright install chromium
npm run test:browser
```

Або використовуйте наявний Chromium:

```sh
CHROMIUM_PATH=/usr/bin/chromium npm run test:browser
```

`APP_URL` дозволяє перевірити інший сервер, зокрема production preview. Smoke-тест перевіряє зміну кокпіта, localStorage, валідацію, редагування B, перемикачі, скидання, мобільну ширину та помилки JavaScript. Скриншоти створюються в `/tmp/bike-desktop.png` і `/tmp/bike-mobile.png`.

## GitHub

Зберігайте вихідні файли та `package-lock.json`. `node_modules/`, `dist/` і кеш TypeScript виключені через `.gitignore`. Перед комітом виконайте перевірки вище та перегляньте `git diff --cached` або `git diff`. Рекомендований коміт: `feat: add bike geometry and cockpit comparison calculator`.


## Публікація на GitHub Pages

Адреса сайту після успішної публікації:

**https://kotovv111-web.github.io/bike-geometry-calculator/**

Одноразове налаштування власником репозиторію:

1. Відкрийте репозиторій на GitHub → **Settings → Pages**.
2. У розділі **Build and deployment → Source** виберіть **GitHub Actions**.
3. Відкрийте **Actions → Deploy calculator to GitHub Pages**. Якщо попередній запуск завершився помилкою через ще не ввімкнений Pages, натисніть **Re-run all jobs**. Також можна запустити **Run workflow** для `main`.
4. Дочекайтеся успішного завершення обох завдань: `build` і `deploy`. Посилання доступне в результатах deployment і в **Settings → Pages**.
5. Відкрийте адресу сайту в Safari на MacBook або iPhone. Встановлення Node.js чи інших програм для користування сайтом не потрібне.

Workflow `.github/workflows/deploy-pages.yml` запускається при кожному push у `main` або вручну. Він встановлює залежності через `npm ci`, запускає математичні тести, перевіряє TypeScript, збирає `dist/` і публікує його через офіційні Pages actions. Доступ на запис обмежено deployment-завданням; окремий токен або секрет не потрібен.

`vite.config.ts` задає базовий шлях `/bike-geometry-calculator/`, щоб JS і CSS правильно завантажувались на сторінці проєкту. Якщо назва репозиторію зміниться, оновіть цей шлях.

Для перевірки production-збірки локально:

```sh
npm run build
npm run preview -- --port 4173
```

Відкрийте `http://localhost:4173/bike-geometry-calculator/`. Для браузерного smoke-тесту з іншим запущеним сервером:

```sh
APP_URL=http://localhost:4173/bike-geometry-calculator/ npm run test:browser
```

На опублікованому сайті змініть проставки: креслення й координати керма мають змінитися. Перейдіть на велосипед B, змініть Stack і перевірте таблицю різниць. Перезавантажте сторінку — коректні параметри мають зберегтися, якщо Safari дозволяє локальне сховище. Дані зберігаються окремо на кожному пристрої та не синхронізуються.

Якщо deployment не запускається, перевірте, що GitHub Actions дозволено в **Settings → Actions → General**. Якщо GitHub повідомляє про недоступність Pages для поточного плану або приватного репозиторію, скористайтеся доступним планом чи публічним репозиторієм. Видимість репозиторію workflow не змінює. Публікація робить застосунок доступним за публічною адресою; персональні параметри калькулятора залишаються у браузері.
